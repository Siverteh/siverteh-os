# Nacre app size, tour interaction and warm publication

Super+M should enlarge Nacre windows to a comfortable centered reading size,
not a full-display window. Bound geometry to logical output size/reserved edges,
restore previous floating/tiled geometry on the second press, keep standard
maximize for other apps. Only Super+S opens Settings.

The tour colors page keeps scene/style/mode/Undo controls; optional apps belong
on the Apps page. App rows must wrap without overlap at narrow or wide sizes.
Welcome scroll uses modest wheel easing, direct pixel movement, no synthetic
touchpad momentum, cancellation on page/scrollbar actions and stable edge stops.

Keep palette ownership and matched image activation. Ready blocking-stdin
transports reuse interpreter/module initialization without idle polling. Serial
requests stream atomic validated presentations then a distinct final result;
failures/restarts release UI busy state and allow retry. Ordinary helper CLI
commands stay compatible. Reuse logo templates/roles once per publication with
byte-identical output. Test bounds/restoration, binding intent, edge scrolling,
responsive text, stream/final-result distinction, process recovery and serialized
publication. Full checks, real app sizing/palette timing/visual/keyboard gates.
